저장소

1 어떤 웹페이지를 앱으로 만들까요?

주소만 넣으면 됩니다. 앱은 이 페이지를 전체 화면으로 열어 줍니다.

앱 이름을 넣으면 자동으로 제안됩니다. 한 번 고치면 더 이상 바뀌지 않아요.

2 아이콘

이미지를 올리거나, 배경색과 글자로 바로 만들 수 있어요. 비워 두면 앱 이름 첫 글자로 자동 생성합니다.

1024×1024 · PNG
배경색
글자색
이미지를 끌어다 놓거나 클릭
PNG · JPG · WEBP — 정사각형으로 가운데를 잘라 1024×1024 로 맞춥니다

아이콘을 보내지 않으면 빌드 서버가 앱 이름 첫 글자를 브랜드 색 배경 위에 그려서 만듭니다. (한글도 지원) 지금은 미리보기만 보여 드릴게요.

3 화면 · 동작 옵션

나중에 다시 빌드하면 언제든 바꿀 수 있습니다.

화면 방향
안드로이드 뒤로가기 버튼
외부 도메인 링크
같은 사이트(서브도메인 포함)는 항상 앱 안에서 열립니다.

핀치 줌 허용 두 손가락으로 확대·축소
당겨서 새로고침 화면을 아래로 당기면 페이지 다시 읽기
상태바 색
앱을 열 때 스플래시 배경과 런처 아이콘 배경에도 같은 색을 씁니다.

4 GitHub 로 APK 빌드

빌드는 GitHub Actions(공개 저장소는 무료)에서 돌아갑니다. 워크플로 파일은 .github/workflows/build-apk.yml 하나뿐입니다.

토큰은 이 브라우저의 localStorage에만 저장되고 api.github.com 외에는 전송되지 않습니다. 공용 PC 에서는 쓰지 마세요.
↗ GitHub Actions 열기
    PAT 없이 쓰기: 위 “JSON 파라미터 복사”로 값을 복사한 뒤 저장소의 Actions → Build APK → Run workflow 에 붙여 넣어도 됩니다. 워크플로 파일이 default 브랜치에 있어야 API 로 실행됩니다.

    무엇이 만들어지나요?

    Capacitor 8 · targetSdk 36(Android 16) · minSdk 24
    결과물: APK (Artifact, 30일 보관) + 선택 시 GitHub Release
    전체화면·뒤로가기·줌·당겨서 새로고침은 생성된 MainActivity.java 에, 화면 방향·cleartext 허용은 AndroidManifest.xml 에, 외부 링크 정책은 capacitor.config.json 에 반영됩니다.
    web2apk · GitHub Actions + Capacitor 8 · 빌드는 저장소의 워크플로에서 실행됩니다.
