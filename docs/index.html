웹페이지 & 앱 이름

주소만 넣으면 됩니다. 앱은 이 페이지를 전체 화면으로 열어 줍니다.

앱 이름을 넣으면 자동으로 제안됩니다. 한 번 고치면 더 이상 바뀌지 않아요.

같은 주소로 다시 빌드하면 새 버전이 됩니다. 설정은 이 브라우저에 자동 저장됩니다.

4

GitHub 로 APK 빌드

빌드는 GitHub Actions(공개 저장소는 무료)에서 돌아갑니다.

토큰은 이 브라우저의 localStorage에만 저장되고 api.github.com 외에는 전송되지 않습니다. 공용 PC 에서는 쓰지 마세요.
↗ GitHub Actions 열기

    PAT 없이 쓰기: “JSON 파라미터 복사”로 값을 복사한 뒤 저장소의 Actions → Build APK → Run workflow 에 붙여 넣어도 됩니다. 워크플로 파일 (.github/workflows/build-apk.yml)이 default 브랜치에 있어야 API 로 실행됩니다.
